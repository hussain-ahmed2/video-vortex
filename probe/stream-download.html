Can a page download a file it holds, with no gesture in the page?

This is the one assumption the whole stream slice rests on: that a script in the page's own world can hand bytes to the browser's downloads with no click inside this page. The extension's own proof runs through the popup, which cannot be scripted. This page loads the real dist/hook.js and asks it directly, so the answer takes one press.

Press Build the streams first. It records four seconds of a canvas locally with MediaRecorder, so the bytes are real and playable with no network at all, then feeds them through a MediaSource in three chunks and also hands the finished blob to a second player. Neither of the two save buttons does anything until that has happened.
